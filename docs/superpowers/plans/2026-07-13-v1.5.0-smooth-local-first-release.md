# ComandOS v1.5.0 Smooth Local-First Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Publish one backward-compatible v1.5.0 release that removes confirmed typing hitches, fixes desktop/touch resizing, replaces the remote mouse emoji with one truthful Select/Interact state, and positions ComandOS as a local-first AI coding-agent terminal.

**Architecture:** Preserve the existing Bash/Python/GTK/WebKit/xterm/tmux architecture. Optimize only measured hot paths, add behavioral tests at each boundary, and keep tmux as the source of truth for terminal state. Documentation and GitHub metadata state precisely that ComandOS has no hosted backend, external ComandOS database, telemetry service, or SSH proxy.

**Tech Stack:** Bash, jq, Python 3 standard library, pytest, Node.js test harnesses, vanilla JavaScript, xterm.js, GTK/VTE, tmux, Git, and GitHub CLI.

## Global Constraints

- All code, tests, documentation, design, implementation plan, and release notes land in exactly one final commit.
- Do not create intermediate commits, tags, releases, or partial GitHub metadata updates.
- Do not stage or commit .playwright-mcp/, json, or subprocess.
- Keep the HTTP API, tmux sessions, SSH file format, local state files, and SQLite schema backward compatible.
- Do not batch terminal input or implement predictive local echo.
- Do not implement incremental JSONL imports, SSE, hidden-terminal suspension, VTE LRU restoration, tab-identity rewrites, or ttyd PAUSE/RESUME.
- Every production behavior change follows RED, verified failure, GREEN, and focused regression verification.

- [ ] **Step 3: Implement a per-refresh flight**

Add a private flight object and keep read_states() outside the lock:

    class _StateFlight:
        def __init__(self):
            self.done = threading.Event()
            self.items = None
            self.error = None

    _state_cache = {"at": 0.0, "items": None, "flight": None}
    _state_lock = threading.Lock()

    def read_states_cached(ttl=1.2):
        now = time.time()
        with _state_lock:
            if (_state_cache["items"] is not None
                    and now - _state_cache["at"] < ttl):
                return _state_cache["items"]
            flight = _state_cache["flight"]
            leader = flight is None
            if leader:
                flight = _StateFlight()
                _state_cache["flight"] = flight
        if not leader:
            flight.done.wait()
            if flight.error is not None:
                raise flight.error
            return flight.items
        try:
            items = read_states()
        except BaseException as exc:
            with _state_lock:
                flight.error = exc
                if _state_cache["flight"] is flight:
                    _state_cache["flight"] = None
                flight.done.set()
            raise
        with _state_lock:
            _state_cache["at"] = time.time()
            _state_cache["items"] = items
            flight.items = items
            if _state_cache["flight"] is flight:
                _state_cache["flight"] = None
            flight.done.set()
        return items
