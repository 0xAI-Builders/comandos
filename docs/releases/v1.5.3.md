# v1.5.3 - Bring terminal links to the foreground

ComandOS v1.5.3 fixes native terminal links that appeared to do nothing when
Brave or another default browser was already open.

## Fixed

- Native URL clicks now pass the ComandOS window and the original mouse-event
  timestamp to GTK. This gives the desktop enough activation context to open
  the link in the configured browser and bring that browser forward.
- Clean clicks and Ctrl+click use the same contextual launch path.
- GIO and `xdg-open` remain fallbacks when GTK cannot handle the URI, while
  macOS and WSL keep their existing launch behavior.

The change does not restart or replace tmux sessions, panes, commands, working
directories, history, or agent processes.

- All 19 native terminal link tests passed.
- Platform compatibility checks passed.
- Both dashboard JavaScript bundles passed syntax validation.
- Brave is registered as the current XDG and GIO HTTPS handler on the release
