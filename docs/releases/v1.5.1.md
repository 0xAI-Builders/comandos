# v1.5.1 - Correct remote terminal wrapping

ComandOS v1.5.1 fixes corrupted wrapped text after the remote terminal changes
width.

## Fixed

- Column changes now reconnect only the browser terminal after a short debounce
  instead of resizing xterm and tmux simultaneously.
- Wrapped rows no longer show duplicated, interleaved, or missing fragments
  after device rotation or split-panel resizing.
- Height-only changes remain live and do not reconnect.
- Repeated width events collapse into one reconnect after the geometry settles.

The reconnect does not restart tmux or any process inside it. Sessions, panes,
working directories, running agents, and tmux scrollback remain intact.

## Verification

- Added a deterministic JavaScript regression test for column and row changes.
- Verified in Chromium against the live remote route with a
  `46 -> 51 -> 46` column cycle.
- Compared rendered wrapped content with `tmux capture-pane` after every
  reconnect.
